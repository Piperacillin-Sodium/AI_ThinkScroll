# 网页创作工作台

工作台使用 HTML/CSS/JavaScript 前端和 Python/FastAPI 后端，提供大纲、目录、草稿、定稿四个创作模块和完整设置模块。设置兼容程序目录下的 `config.json`，原桌面入口 `main.py` 仍可使用。

## 启动

在 `AI_NovelGenerator` 目录双击 `启动网页.bat`，或运行：

```powershell
.\.venv\Scripts\python.exe run_web.py
```

浏览器访问 <http://127.0.0.1:8765>。端口占用时可运行 `run_web.py --port 8766`。

新环境需先安装原有生成依赖及网页依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-web.txt
```

网页从服务地址访问，不能直接双击 `frontend/index.html` 使用。后端默认仅监听本机地址。关闭服务终端会停止后台服务。

## 从已有小说开始

点击顶部“打开目录”，填写本机小说目录的完整路径，例如工作间下的 `实验一`。默认也会尝试登记旧配置 `other_params.filepath` 指定的有效小说目录。

支持用户明确指定的本机外部目录，不使用程序代码目录及其子目录保存小说。未指定路径时，新建小说默认位于工作间的 `小说作品/小说名-编号/`，不会覆盖同名作品。指定已登记目录时打开原作品。

打开旧小说保留原有文件；网页版首次覆盖保存前，会把原文本收入历史。目录解析同时识别中文和英文章名。现有生成引擎暂不支持英文目录续生成，页面会明确提示重新生成，或先将章名改为“第N章”格式。旧小说没有网页定稿记录时，无法自动判断摘要是否已包含某章，首次定稿会显示核对提示。

## 完整创作流程

1. **生成大纲**：填写主题、类型、章节数、字数和全书要求。生成结果先作为候选，预览并采用后写入 `Novel_architecture.txt`，之后可以人工修改。新生成还会产生初始人物状态；已有网页定稿记录时，不用新初始状态覆盖累计人物记忆。
2. **生成目录**：读取已保存大纲，生成 `Novel_directory.txt` 的候选。采用或人工保存后，下方显示章号、标题和梗概。对重复、缺失章号给出提示。
3. **生成草稿**：选择章节，填写本章人物、物品、地点、时间限制和要求；支持引用当前小说 `角色库/分类/角色.txt` 中的资料。先“准备提示词”，采用后可编辑；确认提示词再“生成草稿”，采用候选后人工修改并保存正文。
4. **定稿章节**：读取当前编辑器正文进行审校或扩写，先检查候选再采用。点击“定稿本章”会保存当前正文并更新摘要、人物状态和检索索引。页内可以查看、编辑摘要、人物状态、剧情要点及审校报告。

右侧内容区支持字数统计、字号、专注模式、历史、TXT 导出和 `Ctrl+S`。浏览器在本地保留未保存编辑；正式写入小说仍以“保存修改”或“采用结果”为准。浏览器存储空间或隐私模式限制会影响本地恢复，重要内容应及时保存。

全书默认要求、目录要求、本章创作要求和审校/扩写要求按页面及章号隔离，本章临时要求不会写回全书默认参数。

## 候选、版本和任务

- 大纲、目录、提示词、草稿、审校和扩写都先产生候选。候选预览只读，采用后到主编辑器修改、保存。
- 候选采用时校验任务开始时的文件版本。文件已被其他操作修改时返回冲突，避免覆盖新编辑。
- “历史”载入旧版本到编辑器，确认后保存；载入不会立即改变磁盘文件。
- “任务记录”可以重新打开当前小说的旧任务与未采用候选。刷新、换页和关闭浏览器不影响仍在运行的后端任务。
- 首版单个生成执行器依次处理任务；同一小说有未结束任务时，其他生成和文件提交会等待用户先结束当前任务，编辑器仍可保留编辑。
- 模型返回全文后更新内容；阶段和日志会持续反馈。当前版本未提供逐字流式正文。
- “停止任务”阻止后续步骤，正在等待的模型请求可能需要返回或超时。正文与记忆一旦提交，将完成该步的收据和索引状态登记，再响应后续停止。
- 服务重启后，原运行任务标记为“中断”，不会自动重新调用模型。大纲与目录可以使用“继续生成”恢复匹配输入的检查点；改变主题、模型或要求后应重新生成。旧桌面检查点没有输入指纹，导入时会提示核对。

## 定稿和批量创作

同一正文版本再次定稿不会重复生成摘要和人物状态；如果只有向量索引失败，则仅重试索引。界面会区分“已定稿”和“检索待补建”，可点击“补建检索记忆”。密钥、网络或向量服务出错，不会抹掉已提交的正文和记忆。

修改早期已定稿章节后，从该章重新定稿。系统使用该章原始定稿前的记忆基线重新生成，并把后续章节记忆标为待重建；随后按章顺序重新定稿。旧版本可在历史中查看。

“批量顺序创作”执行每章的提示词、正文、可选扩写和定稿。后章使用前章刚更新的记忆。已定稿且索引完成的版本会跳过；遇到未定稿旧正文会停下，避免覆盖。字数仍低于最低值时保留可采用候选并停止；索引失败时保留已完成内容并停止。批量任务直接保存已确认的流程结果，启动前会说明这一点。

章节索引使用稳定的章号/分块 ID。重复定稿替换该章索引并移除该章多余分块，不删除其他章节或外部知识。旧桌面索引没有章号元数据，首次迁移无法自动辨认其中同章的旧片段；以后通过网页创建的章节索引可稳定去重。

## 配置与文件

设置页保留原软件的全部设置字段和操作，并补充了预设复制、并发修改检查及知识文件重新入库。分组及原字段对应关系见 [设置兼容清单](settings-compatibility.md)。无需先创建小说即可管理模型和连接。

- **模型预设**：选择、新增、复制、重命名、删除；编辑接口格式、模型名、Base URL、API Key、Temperature、Max Tokens、Timeout，测试当前填写的配置。重命名会同步任务引用，删除后至少保留一个预设。
- **任务模型**：分别配置大纲、目录、提示词与草稿、定稿、一致性审校使用的模型。
- **Embedding**：管理 Embedding 预设、接口格式、模型名、Base URL、API Key、Retrieval Top-K；测试连接并显示向量维度。
- **创作默认值**：包含原有 11 项小说参数及中英文创作模式。默认参数用于新建小说，已有小说继续保留各自参数；创作语言切换会用于后续任务的生成提示词。
- **代理设置**：启用状态、代理地址和端口。
- **WebDAV 备份**：地址、用户名、密码，连接测试、备份和恢复。远程位置沿用 `AI_Novel_Generator/config.json`，备份包含模型凭证；恢复前会把当前配置保存至程序的 `backup/` 目录。
- **知识库管理**：导入 UTF-8、GBK / GB2312 编码的 TXT/Markdown 资料，查看入库状态，清理索引或从保留的源文件重新入库。此组操作针对当前打开的小说。

“保存全部设置”写入 `config.json`；“加载配置”重新读取磁盘配置。新任务读取最新配置，正在运行的任务继续使用启动时快照。配置在其他页面或桌面端改变时，保存会提示冲突并保留当前编辑，加载最新配置后再修改。

已有 API Key 和 WebDAV 密码不会返回浏览器。输入框留空保留原值，填写后替换，勾选清除才删除。密钥和密码草稿只在页面内存中保存，不写入浏览器本地存储。测试连接可使用尚未保存的输入；WebDAV 备份使用已保存的完整配置。

模型测试会读取点击按钮时输入框里的实际值，并在日志中显示本次预设、接口和模型名称。修改参数后会清除旧的测试反馈；若服务报“模型不存在”，请核对本次提交的模型名称及后面的服务原始错误。预设名称是本地标签，模型名称是服务商接受的模型 ID；Azure OpenAI 则按 URL 中的部署名调用。创作页同时显示预设与模型 ID；有未保存设置时，开始创作会先提示保存，保存失败则不提交任务。

知识资料以稳定的文件/分块 ID 入库，重复导入更新同一份资料，不叠加重复片段。清理会移除当前小说的全部向量集合，并重置向量维度约束；正文、摘要、人物状态及 `.knowledge/` 中的源文件保留。清理后可以重新导入资料，并在定稿页补建各章检索记忆。更换 Embedding 模型后，旧索引可能需要这样重建。

小说内容仍使用原 TXT 文件。新增 `prompts/chapter_N.txt` 保存确认提示词，`reviews/chapter_N.txt` 保存审校报告，`.web-checkpoints/` 保存大纲和目录检查点。`backend/runtime/` 保存 SQLite 项目登记、任务日志、历史版本、定稿收据和隔离任务目录；该目录已排除 Git。保留历史时应同时备份小说目录和 runtime。

顶部“导出小说”支持按章合并 TXT 和文本 JSON 备份，不导出密钥、向量库或网页任务数据库。WebDAV 只备份配置，不备份小说文本；完整迁移作品时请同时保留小说目录和 runtime。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --test tests/test_web_settings_frontend.mjs
```

测试使用临时小说、模拟模型及模拟 WebDAV，覆盖 HTTP/生成编排、候选与历史、续生成、取消、定稿幂等与回退、批量记忆衔接、全部设置字段与凭证处理，以及真实 Chroma 持久化、知识入库和清理后重建。不会调用用户的付费模型。实际模型输出质量、配额和服务连通性仍取决于 `config.json` 中配置的提供方。
